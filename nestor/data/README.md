# data/ — научный справочник (не подключён)

Сюда после сверки версий кладётся выбранный снимок научной Y-STR-базы
(файл `.db` в git не попадает) и `MANIFEST.json`:

```json
{
  "file": "Nestor_scientific_YSTR.db",
  "sha256": "<sha256 файла>",
  "profiles": 0,
  "source": "откуда снимок (архив/версия/дата)",
  "selected_reason": "почему выбран этот снимок; чем объясняется расхождение 45 389 / 35 284"
}
```

Пока `MANIFEST.json` нет, приложение работает без справочника и пишет об этом
на главной странице. При несовпадении SHA-256 справочник не открывается.
Открытие — только на чтение (`mode=ro`, `PRAGMA query_only`).

Профили FTDNA (326 тыс.) сюда не добавляются ни в каком виде.
