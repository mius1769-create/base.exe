# Аудит архива экспертного приложения Genopoisk (для NeSToR)

Статус: **черновик — архив в сессию Claude ещё не поступил.** Ниже разделены
сведения, проверенные Claude, и сведения, сообщённые заказчиком / предварительным
аудитом в сессии Codex. Разделы «ожидает проверки» заполняются запуском
`tools/audit_archive.py` и разбором кода.

## Границы

* Архив используется только для аудита кода и правил. Его базы не копируются
  в NeSToR, не импортируются и не меняются; код архива не исполняется.
* Не подключаются: локальная база GenopoiskGD, выгрузки FTDNA (~320 тыс. профилей).
* Научный снимок архива (45 389) и кандидат `Nestor_scientific_YSTR.db` (35 284)
  не объединяются; сравнение — только для аудита состава и происхождения.
* `data/MANIFEST.json` фиксирует только снимок, выбранный по итогам сверки
  источников; автоматического выбора снимка 45 389 нет.

## 2. Правила сравнения STR (сообщено, код не проверен Claude)

| Тема | Сообщено (Codex) | Правило NeSToR | Статус |
|---|---|---|---|
| Genopoisk Y37 ↔ FTDNA | Y-GATA-H4 − 1 | T12 | предварительная калибровка |
| Genopoisk Y50 ↔ FTDNA | Y-GATA-H4 − 1, DYS520 − 5, A10 − 2 | T13 | предварительная калибровка |
| Genopoisk ↔ Genopoisk | 1:1, без поправок | T14 | предложено |
| Научные профили другой шкалы | сравнение отмечается как предварительное | T15 | предварительная калибровка |
| Мультикопийные локусы | ожидает разбора кода (в `RELEASE_VALIDATION`: «multicopy switch») | — | ожидает |
| Дробные аллели | ожидает разбора кода («ForenSeq decimals») | T10 (только NIST, двоичные дроби xlsx) | ожидает |
| Пропуски / no-call | ожидает разбора кода («no-call/review handling») | T09 (NIST `del`) | ожидает |
| DYS389 | ожидает разбора кода («DYS389B exclusion») | T03, T04, T05 | ожидает |

Принцип для всех правил: опубликованное/исходное значение хранится отдельно
(`raw_records`), профиль сравнения строится отдельно (`nestor_app/reference_rules.py`)
со списком применённых правил; межпанельные поправки до подтверждения кодом и
контрольными файлами имеют статус `preliminary` и молча не применяются.

Nestor_scientific_YSTR.db` — источники только в снимке архива, расхождения в
общих источниках; объединения нет.

## 4. `user_scientific_since_20261008` — 8 026 записей

Сообщено: в метаданных указано, что индивидуальное происхождение профилей не
проверено и возможны пересечения публикаций. Решение: **не включать** в основной
научный справочник без отдельной сверки (происхождение каждой записи, дубли с
опубликованными источниками). Проверка состава — ожидает файла.
