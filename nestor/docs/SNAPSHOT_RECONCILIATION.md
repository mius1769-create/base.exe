## Решение по снимку

Снимок **не выбран, справочник не подключён** (`data/MANIFEST.json` не создан).
Объединять снимки вслепую нельзя. Варианты:

1. **Передать архив** (`.tar.gz`, SHA-256 выше). Тогда:
   `py -3 tools/inspect_reference.py scientific.sqlite --compare Nestor_scientific_YSTR.db`
   покажет 23 недостающих источника и расхождения в 6 общих; по итогу выбираем снимок
   и фиксируем его в `MANIFEST.json`.
2. **Зафиксировать 35 284 сейчас** как проверенный по контрольной сумме снимок
   (кандидат манифеста ниже), с пометкой, что 23 источника архива не включены.

## Что важно до подключения к поиску

* **Номенклатура.** Значения сохранены «как опубликовано», **без FTDNA-смещений**.
  Пользовательские профили FTDNA для части маркеров используют другую нумерацию,
  поэтому GD между пользователем и справочником без таблицы пересчёта будет ложным.
  Таблица пересчёта и правила (в архиве упомянуты «DYS389B exclusion», «multicopy
  switch», «ForenSeq decimals», no-call) должны прийти из архива — придумывать их не буду.
* **Имена маркеров.** В базе встречаются `Y GATA H4` и `GATA H4` (сводятся к `Y-GATA-H4`),
  `DYS389B` (= DYS389II−I у Underhill; в GD не учитывать, иначе двойной счёт),
  `DYF403S1A/B` и `DYS526A/B` — разные локусы, а не копии.
* **Права.** Для открытой базы явно пригодны только источники CC BY (Purps, Ballantyne —
  31 902 записи). Balanovsky и Underhill (1 805) — только локальное исследование;
  NIST и Roewer — по условиям источников. В локальном MVP это допустимо, для любой
  публикации нужно решение по каждому источнику. Файл базы в git не кладётся.
