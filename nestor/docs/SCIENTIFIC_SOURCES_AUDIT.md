Сгенерировано `tools/render_source_audit.py` из `data/source_audit.json` и `docs/QC_SUMMARY.json`. Дата аудита: 2026-11-03. Не редактировать вручную.

Кандидат: `Nestor_scientific_YSTR.db`, 35284 записей, SHA-256 `c6f713b1a0db0966fbabbfaae8fc926934ddd3131fccb591d7686719a7ba7d7d`. Научный кандидат. Не база Genopoisk GD, не пользовательские данные, не FTDNA-выгрузки. Со снимком 45 389 из архива не объединяется.

## Правила аудита

* Сырые значения не исправляются и не перезаписываются; ошибки — в QC (docs/QC_SUMMARY.json), преобразования — в data/transform_rules.json
* Лицензия статьи не считается лицензией на дополнительные таблицы
* Свободный доступ к статье не считается разрешением на перепубликацию данных
* Ни один источник не подключён к пользовательскому поиску NeSToR
* Импорт в справочник — только для источников со статусом «допущен»
* Из сессии закрыты сайты издателей, PMC и NIST: условия установлены по вторичным записям; поле «подтверждено» везде `нет`, пока первичная страница не прочитана.
