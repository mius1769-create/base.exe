# Локальный тестовый научный каталог NeSToR

**Назначение: только локальное тестирование.** Каталог не является научным справочником
NeSToR, не публикуется, не подключается к облаку и не попадает в git
(`var/test_catalog/`, `var/` в `.gitignore`). Публикационная сборка не создаётся.
Право на повторное использование ни одного источника не подтверждено; включение всех
научных неперсональных записей, в том числе со статусом «не проверено» и «исключён»,
разрешено заказчиком только для локального тестирования.

Сводка без записей: [TEST_CATALOG_SUMMARY.json](TEST_CATALOG_SUMMARY.json).
Сборка: `nestor_app/test_catalog.py`, `tools/build_test_catalog.py`.

## Правила объединения

* Строки **не объединяются по совпадению гаплотипов**: каждая первичная запись источника —
  отдельная запись каталога.
* Дубли копирования снимаются только на уровне **источника целиком**: общие источники
  Purps 2014 (`Scientific_Purps2014_PPY23` = `purps2014`) и NIST 1032
  (`Scientific_NIST1032_UAS24` = `nist2022`) сравниваются по опубликованным значениям
  всех записей. Совпали полностью → берётся копия архива (подробнее происхождение: файл,
  лист, строка, QC-статусы), копия кандидата не добавляется. Если бы копии различались,
  остались бы обе с пометкой.
* Коллизии ID источника сохраняются как отдельные записи с флагом «коллизия ID».
* `user_scientific_since_20261008` — агрегированные наблюдения гаплотипа с числом N из
  источника; у каждой — ссылка на публикацию (как записана) и флаг «возможное
  пересечение публикаций», если в том же снимке есть индивидуальная запись того же
  источника с тем же гаплотипом. Пересечения только помечаются, записи не удаляются.
* У каждой записи: источник, публикация, ID образца, файл / лист / строка, шкала аллелей,
  лицензия (как в метаданных), статус проверки и пометка
  «локальное тестирование; право на повторное использование не подтверждено».
* Значения: исходные — дословно (`raw_markers_json`); позиции для сравнения — отдельно
  (`positions_json`): корректные — числа, `not_read` — нет значения, прочие QC-статусы и
  нечисловые значения — «не распознано» (в GD не входят).

## Поиск и пометки

* Каталог выключен по умолчанию; сборка его не включает.
* Включённый каталог показывается **отдельным разделом** результатов (гостевой поиск и
  поиск владельца): «Научный тестовый каталог — ЛОКАЛЬНОЕ ТЕСТИРОВАНИЕ», с баннером о
  непроверенных данных; у каждой строки — вид записи (индивидуальная / агрегированная,
  N), «GD (предварительно)» (шкалы источников не откалиброваны, T15), статус проверки,
  пометка о праве на повторное использование и флаги.
* Каталог не смешивается с пользовательскими профилями и не влияет на гостевую выборку 20%.
* Выключение и удаление действуют без перезапуска: флаг проверяется при каждом запросе.

## Проверка форматов (синтетические файлы, tests/fixtures/formats)

`tests/test_formats.py`: FTDNA Y12 / Y25 / Y37 / Y67 / Y111 и Genopoisk Y37 / Y50 в
CSV (`;` и `,`), TSV, XLSX и вставленной таблице — распознавание и выбор панели,
точные значения, число позиций и аллелей (12 / 25 / 37 / 67 / 111; Genopoisk Y37 — 36,
Y50 — 52 значения по составу архива); пользовательские наборы на 18 и 50 значений с
явными заголовками (панель не распознаётся); отказ для строки значений без заголовков
(состав по числу значений не угадывается, в том числе при выбранной панели); пропуски
(пусто, «0», «-»), дроби (T18), копии в колонках a/b/c/d и разное число копий (T17),
DYS389 (T16: II − I и опубликованный DYS389B), нераспознанные значения; сравнение GD 0 / 1
/ 2, межпанельное пересечение и поиск по синтетическому тестовому каталогу.

## Команды

```bash
py -3 tools/build_test_catalog.py build --candidate ПУТЬ\К\Nestor_scientific_YSTR.db --archive ПУТЬ\К\scientific.sqlite --summary docs/TEST_CATALOG_SUMMARY.json
```

```bash
py -3 tools/build_test_catalog.py enable
```

```bash
py -3 tools/build_test_catalog.py disable
```

```bash
py -3 tools/build_test_catalog.py remove
```

```bash
py -3 tools/build_test_catalog.py status
```

`remove` удаляет файл каталога и флаг из папки приложения; это обычное удаление файла
(физическое стирание с SSD не гарантируется).
