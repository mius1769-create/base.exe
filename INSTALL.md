# Установка GENOPOISK CRM — пошаговая инструкция

Эта инструкция рассчитана на человека, который ничего не знает о проекте.
Если что-то не получается на каком-то шаге — не переходите к следующему,
разберитесь на месте.

---

## Шаг 1. Скачать архив

Скачайте `GENOPOISK_CRM_source.zip` и распакуйте в любую папку, например
`C:\GENOPOISK_CRM\`. Внутри должна быть папка `app`, файл `run_app.py` и
другие файлы — если видите просто ещё один архив внутри, распакуйте и его.

> Если у вас уже есть готовый `GENOPOISK_CRM_Setup.exe` (собранный через
> GitHub Actions) — шаги 2–4 можно пропустить, сразу переходите к
> [обычной установке через инсталлятор](#если-у-вас-уже-есть-exe).
> Шаги 2–4 нужны только для запуска из исходного кода.

## Шаг 2. Установить Python

1. Зайдите на https://www.python.org/downloads/
2. Скачайте Python версии **3.11 или новее** для Windows.
3. При установке **обязательно поставьте галочку "Add python.exe to PATH"**
   на первом экране инсталлятора — без неё следующие шаги не сработают.
4. Проверьте, что всё встало: откройте командную строку (Win+R → `cmd` →
   Enter) и наберите:
   ```
   python --version
   ```
   Должно показать что-то вроде `Python 3.12.3`. Если пишет "не является
   внутренней или внешней командой" — Python не в PATH, переустановите с
   галочкой из пункта 3.

## Шаг 3. Установить зависимости

1. В командной строке перейдите в папку с распакованным проектом:
   ```
   cd C:\GENOPOISK_CRM
   ```
   (замените путь на свой, если распаковали в другое место)
2. Установите всё необходимое одной командой:
   ```
   pip install -r requirements.txt
   ```
3. Это займёт несколько минут — скачиваются PySide6 (интерфейс), openpyxl
   (работа с Excel) и pyinstaller (для сборки exe, для обычной работы не
   нужен, но не помешает).

## Шаг 4. Запустить программу

```
python run_app.py
```

Через несколько секунд должно открыться окно программы. Если появилось
окно с таблицей (пока пустой) — всё получилось, переходите к шагу 5.

Если появилась ошибка про отсутствующий модуль — вернитесь к шагу 3 и
проверьте, что `pip install` отработал без ошибок.

---

## Если у вас уже есть .exe

1. Запустите `GENOPOISK_CRM_Setup.exe`.
2. Мастер установки спросит папку — можно оставить по умолчанию, можно
   изменить. Поставьте галочку «Создать ярлык на рабочем столе», если
   удобно.
3. После установки программа запускается сама, либо через ярлык.
4. Python и остальные зависимости устанавливать не нужно — инсталлятор
   уже содержит всё необходимое.
5. Переходите сразу к шагу 5 ниже.

---

## Шаг 5. Создать БД

**Ничего специально делать не нужно.** При самом первом запуске программа
сама создаёт пустую базу данных со всеми справочниками (типы тестов,
способы доставки и т.д.) в файле:

```
%APPDATA%\GENOPOISK_CRM\data\genopoisk.db
```

Чтобы посмотреть, где это физически на диске — нажмите Win+R, вставьте
`%APPDATA%\GENOPOISK_CRM\data\` и нажмите Enter, откроется папка с
файлом `genopoisk.db`.

**Если у вас уже есть готовая база** (например, `genopoisk_migrated.db`
после переноса старых данных) — закройте программу, если она открыта, и
скопируйте ваш файл на место автоматически созданного, с точно таким же
именем `genopoisk.db`, в ту же папку `%APPDATA%\GENOPOISK_CRM\data\`.
Замену подтвердите. При следующем запуске откроется уже она.

## Шаг 6. Подключить Telegram

**Это не обязательно для начала работы** — программа полноценно работает
и без Telegram, все заказы можно вносить вручную или через импорт Excel.

Когда у вас будет готовый Telegram Bot Token:

1. Откройте программу → кнопка «Настройки» на верхней панели.
2. Перейдите на вкладку «Telegram».
3. Вставьте токен в поле «Bot Token» → «Сохранить».

Токен сохраняется только на этом компьютере, в отдельном файле
`%APPDATA%\GENOPOISK_CRM\secrets\secrets.json` — не в базе данных и не
где-либо ещё.

⚠️ На данный момент это только место для хранения токена. Сам
автоматический приём сообщений из Telegram в текущей версии программы
**ещё не реализован** — это будет добавлено отдельно, когда до этого
дойдёт очередь разработки.

## Шаг 7. Сделать первый backup

1. Настройки → вкладка «Резервные копии» → укажите папку, куда сохранять
   копии (можно создать обычную папку на диске, например
   `C:\GENOPOISK_CRM_backups\`, или папку внутри Яндекс.Диска/OneDrive,
   если хотите, чтобы копии сами уходили в облако).
2. Сохраните настройки.
3. Вернитесь на главный экран → кнопка «Резервные копии» на верхней
   панели → «Создать резервную копию сейчас».
4. В указанной папке появится файл вида
   `genopoisk_2026-08-13_14-30-00.db` — это и есть ваша резервная копия.

С этого момента рекомендуется делать backup регулярно (программа умеет
делать это автоматически раз в сутки, если папка уже указана — просто
держите программу открытой хотя бы иногда).

---

## Что делать, если что-то пошло не так

- **Программа не открывается / сразу закрывается**: запустите через
  командную строку (`python run_app.py`), а не двойным щелчком — тогда
  будет видно текст ошибки.
- **Не видно старых данных**: проверьте, что файл `genopoisk.db` лежит
  ровно в `%APPDATA%\GENOPOISK_CRM\data\`, а не рядом с программой.
- **Нужно начать заново**: закройте программу, переименуйте или удалите
  `genopoisk.db` в папке из шага 5 — при следующем запуске создастся
  новая пустая база (старая при этом никуда не денется, если вы её
  переименовали, а не удалили).
