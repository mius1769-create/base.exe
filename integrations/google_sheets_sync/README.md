# Синхронизация CRM → Google Sheets

`sync.py` читает локальную базу CRM (только чтение) и выгружает статусы тестов
в две вкладки Google-таблицы: «Рабочая» (для сотрудников) и «Клиентская»
(статусы для клиентов). Перед перезаписью сохраняется резервная копия.

Клиентские статусы считаются функцией `app.business_logic.client_status_label`
— это та же логика, что нужна для личного кабинета.

Настройка (переменные окружения):

| Переменная | Назначение |
|---|---|
| `CRM_GOOGLE_SHEET_ID` | ID Google-таблицы (обязательно для `--sync`) |
| `CRM_DB_PATH` | путь к `genopoisk.db` (по умолчанию `%APPDATA%\GENOPOISK_CRM\data\genopoisk.db`) |
| `CRM_APP_ROOT` | корень проекта CRM (по умолчанию — два уровня выше этого файла) |
| `CRM_SYNC_ROOT` | папка для `token.json`, `backups/`, `logs/` (по умолчанию — эта папка) |

`token.json`, `credentials.json`, `backups/` и `logs/` в репозиторий не попадают.

```
python sync.py --dry-run   # проверить выгрузку без отправки
python sync.py --sync      # отправить в Google-таблицу
```
